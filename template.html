PacketScope

Turn packet captures into network intelligence

A cybersecurity web app for analyzing network traffic. Upload a .pcap or .pcapng file and the FastAPI back end parses it with Scapy. The React front end then shows the protocols, top talkers, services and packet sizes, with no Wireshark install needed.

  • Traffic summaries with protocol counts, top source and destination IPs, top services by port, and packet-size stats
  • JWT authentication, user and admin roles, and an admin activity log that keeps its history even after a user is deleted
  • Tags and notes on each capture, with hand-built SVG charts (no chart library) and WCAG AA contrast

TeamMERNSecurity

CyberTrack

Incident tracking, from detection to resolution

A full-stack MERN app where analysts report incidents, link threat indicators (IPs, domains, malware, phishing artifacts) to them, and open investigations assigned to team members. Each case keeps a full record from the first report to the final fix.

My part: I built the Incidents resource: the data model, the REST API (create, read, update, plus admin-only delete) and the React pages for it.
  • Role-based permissions: analysts can create and update, and only admins can delete, so the records stay a reliable audit trail
  • Dashboard with open incidents, severity breakdowns and active investigations
  • Email alerts when a critical incident is created or an investigation is assigned

SoloFull-stackPrivacy

Hawiyati هويتي

Your identity, your way

A digital identity card platform. One account holds several shareable cards (Professional, Personal, Emergency), and each card has its own QR code and short link. Every card shows only the fields you choose, so a recruiter, a stranger and an emergency contact each see what fits.

  • Visitors scan the QR code, open the public card and tap Save Contact to download a vCard, with no app to install
  • Google OAuth sign-in, CSRF tokens, session regeneration, login rate limiting and helmet security headers
  • Cards can be paused or set to expire, and admins can suspend accounts, with every admin check made against the database

Connect Four

The classic game, built from scratch

My first solo bootcamp project: a responsive Connect Four game in plain HTML, CSS and JavaScript with no framework. I used it to practise DOM manipulation, grid logic and turn-based state.

  • Two-player and vs-computer modes. The computer takes winning moves and blocks yours
  • Win detection with the winning line highlighted, plus a timer with pause, confetti and a dark/light theme
  • Scores, leaderboard and game state are saved to localStorage, so a refresh doesn't lose them
