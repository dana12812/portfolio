# Dana Al Saleh: Portfolio

Personal portfolio of Dana Al Saleh, software engineer and cyber threat analyst in Bahrain.

Built with React and Vite. Live at https://danaalsaleh.vercel.app

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Site content (projects, journey, certificates, links) lives in `src/data.js`.
